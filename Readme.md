# 🌌 Orbital Strike

**Orbital Strike** is a classic 2D arcade space shooter game built in Python using the **Pygame** library. Take control of your spaceship, shoot down incoming enemy vessels, and survive as long as possible to achieve the highest score!

---

## 🎮 Gameplay & Features

* **Smooth Movement:** Move your spaceship left and right to dodge and align shots.
* **Laser Combat:** Fire laser projectiles equipped with immersive sound effects (`piw.wav`).
* **Progressive Difficulty:** The enemy ship accelerates every time you destroy it, raising the stakes.
* **Live Score Board:** Track your current points dynamically in the top-left corner.
* **Game Over Screen:** Features a blurred dark overlay with a glowing red "GAME OVER!" warning.
* **Instant Restart:** Click the "Play Again" button to restart a new match immediately without closing the application.
* **Audio Atmosphere:** Features looping space background music and dedicated sound effects.

---

## ⌨️ Controls

* ⬅️ **Left Arrow:** Move spaceship left
* ➡️ **Right Arrow:** Move spaceship right
* ⎵ **Spacebar:** Fire laser
* 🖱️ **Left Click:** Click the "Play Again" button on the Game Over screen

---

## 🛠️ Requirements & Installation

> ⚠️ **Important:** To run the game properly, you must download **all files and folders** from this repository (including the `Assets/` directory) and keep them in the same project folder.

1. **Download or Clone the Project:**
   Ensure you have downloaded the entire project. If you use Git, run:
```bash
git clone https://github.com/pavelgetzov-creator/Orbital_Strike
cd orbital-strike
```

2. **Install Pygame:**
   Make sure you have Python installed, then run the following command in your terminal:
```bash
pip install pygame
```

3. **Run the Game:**
   Launch the main script to start playing:
```bash
python main.py
```
